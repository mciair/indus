# Indus CLI

India's first AI-native command-line (CLI) coding agent, built by
**Mantra [MCIAIR]**.

## Install

```sh
npm install --global indus-cli
```

Then launch Indus with any supported command name:

```sh
indus
indus-cli
induscli
indusai
indus-ai
mantra
mantra-ai
```

The npm launcher downloads the verified native Indus v0.1.0 binary for the
current operating system and architecture on first use. Linux, macOS, and
Windows are supported on x64 and Arm64.

Documentation: [docs.mciair.in](https://docs.mciair.in)

Source: [github.com/mciair/indus](https://github.com/mciair/indus)
